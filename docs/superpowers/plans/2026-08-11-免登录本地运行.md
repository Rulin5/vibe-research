# 免登录本地运行实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Vibe-Research 的公共数据功能无需登录或访问密钥即可在本机完整启动，并以中文说明运行方式与真实数据来源。

**Architecture:** 删除 `VR_API_KEY` 这一应用层访问密钥契约及所有浏览器 Authorization 头生成逻辑；API 仍以本机回环地址运行，模型调用仍是用户可选的外部能力。保留元数据地址封锁，避免因移除访问密钥而将用户传入的模型地址直接暴露给云元数据服务。

**Tech Stack:** FastAPI、React 19、TypeScript、Vite、pytest、Node 原生测试。

## Global Constraints

- 所有用户可见说明使用中文；协议名、命令、URL、模型和供应商专名保留原样。
- 公共金融数据必须保留数据来源、市场和可用性说明；不得将数据源异常伪装成零值。
- 不新增第三方依赖；API 继续仅在 `127.0.0.1:8900` 本机回环地址运行。
- AI 是可选功能；基础数据看板、持仓和研报管理不得依赖第三方模型登录或 API Key。
