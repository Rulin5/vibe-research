# 公网发布门禁

任何一项未通过，状态均为“不可正式公网发布”。

- [ ] `deploy/production.env` 中不存在 `CHANGE_ME`，且密钥未进入代码、镜像层或日志。
- [ ] 正式域名与 TLS 证书有效，HTTP 自动跳转 HTTPS，Cookie 带 `Secure`。
- [ ] PostgreSQL、Redis、ClamAV 和 API 就绪检查全部健康。
- [ ] Alembic 在生产备份后成功升级到 `head`，并记录迁移输出。
- [ ] 注册、登录、退出、跨用户持仓/研报/笔记/资产方案隔离测试通过。
- [ ] AI 默认系统 Key 与用户自有 Key 切换测试通过；出站域名限制与私网 SSRF 拦截通过。
- [ ] 25MB 原文件边界、错误 base64、扩展名拒绝、EICAR 恶意文件拒绝测试通过。
- [ ] 前端单测、构建、后端单元/接口/迁移测试和依赖审计通过。
- [ ] 数据供应商的生产授权、展示口径、缓存期限与再分发边界得到书面确认。
- [ ] PostgreSQL 与报告卷完成备份，并在隔离环境完成恢复演练。
- [ ] 5xx、依赖故障、磁盘容量、证书到期、数据源失败率已有可执行告警。
- [ ] 隐私政策、用户协议、风险揭示、数据删除与客服处理流程完成审核。
- [ ] 个性化适当性与资产配置联动保持禁用，直至其金融合规、计算口径和用户隔离门禁独立通过。
- [ ] 人工冒烟覆盖桌面端与移动端关键入口。

本清单不包含验证码门禁；登录保护由 Nginx 与 Redis 双层限流承担。

最终发布命令前必须运行 `python deploy/scripts/check_release_gate.py --evidence <证据清单>`。Markdown 勾选不构成证据，校验器退出码非零时不得发布。
