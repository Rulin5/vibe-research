# 行业板块最新交易日日线数据

## 目标

将板块中心的“行业”改为 TeaJoin/Tushare `moneyflow_ind_ths` 返回的可用行业集合，并展示该接口最新可获得交易日的真实收盘涨跌幅；概念分类继续使用 `ths_index` 主数据，不混入不同口径的行情。

## 数据口径

- 行业定义、代码、收盘价、涨跌幅、成分公司数、领涨股、资金净额：`moneyflow_ind_ths`。
- 最新交易日：从上交所交易日历倒序尝试，选择首个返回行业记录的交易日；不将无数据伪装为零值。
- 概念定义和成分股：`ths_index(type=N)` 与 `ths_member`。
- 日线数据不是实时行情；接口返回的 `as_of` 必须在界面展示。

## 工作包

1. 为 TeaJoin 行业日线增加交易日回退、标准化和短缓存，并用日线结果构造行业列表。
2. 增加后端契约测试，覆盖当天数据、非交易日回退和概念不混入行业日线字段。
3. 扩展前端类型和板块卡片/详情展示，标明最新交易日与日线来源。
4. 运行受影响测试、前端构建和实际 TeaJoin 冒烟查询。
